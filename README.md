# Cheesy-Lab-V1
<b>Cheesy Lab</b> is a pixel-art pizza experimentation game where players step into a role of a mad scientist working in an abandoned laboratory, conducting forbidden experiments on pizza, mixing different ingredients, baking different pizzas from delicious masterpieces to cursed disasters.

Player chooses from 5 options of each category:
Crust 🫓
Sauce 🍅
Cheese 🧀
Toppings 🍕
Seasoning 🧂

Combining these Ingredients to bake different pizzas, gives quirky badges, fabulous title, from basic to epic!

The pixel art adds life into the lab...
